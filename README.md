## ❔ What's this?

This repository contains source code and documentation for modding the video game **[Traction Point](https://store.steampowered.com/app/1485840/Traction_Point/)**, developed by Madrigal Ltd.

You need to have a copy of Traction Point to play any mods created for it. At the time of writing Traction Point has not been released, but you can join the Madrigal [Discord Server](https://discord.gg/k8CxSpsCnB) to get access to a pre-release version of the game.

## 🚀 Getting Started

Please see the [wiki](https://github.com/MadrigalGames/TractionPointModding/wiki) for instructions on how to get started.
